# 한계 및 판정 의미

- `PASS`는 구현된 정적 검사 범위에서만 이상이 없다는 뜻입니다.
- `WARN`은 휴리스틱 또는 수동 검토 대상입니다.
- `FAIL`은 명확한 파일 손상, 누락, 중복 또는 수식 텍스트 차이입니다.
- `NOT_CHECKED`는 Pandoc 부재와 같은 도구/자료 부족 상태입니다.

현재 기본 배포는 MCP 요청에서 검증 가능한 사용자 주체를 전달받지 않는 내부망
단일 테넌트 모델입니다. `job_id` 형식과 작업 존재 여부는 검증하지만 사용자별
소유권 분리는 제공하지 않습니다. 다중 사용자 격리가 필요한 배포에서는 LibreChat
사용자 신원 전달과 서버 측 소유권 저장·검증을 별도로 활성화해야 합니다.

이 서버는 번역 의미 정확성, 원본 PDF 추출 정확성, LaTeX와 OMML의 수학적 동치, Word의 최종 시각 품질을 자동으로 보증하지 않습니다.
